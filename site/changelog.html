版本日志

25 个发布版本，当前版本是 7.3.0。这里展示 13 个主要版本，破坏性变更单独标出。

25 个发布版本 · 展示 13 个

在 GitHub 阅读完整 CHANGELOG
7.3.02026-10-26发布
  • 新增全链路性能基准（HTTP/gRPC + MySQL 9 + Redis 7）：8 并发、每轮 1 万请求 × 5 轮；读路径 0/100,000 次 ≥10ms，HTTP max 5.9–9.2ms、gRPC 6.0–8.4ms。
  • HTTP（含 TLS accept loop）与 gRPC 服务端启用 TCP_NODELAY，消除 Nagle + 延迟 ACK 带来的毫秒级尾部。
  • 新增 examples/fullchain-bench、scripts/perf/fullchain.sh 与 docs/performance.md；ecat-bench 增加 p99.9、max 与超阈值计数。
  • 静态站新增客户端全文搜索，支持 Ctrl/Cmd+K 与 / 快捷键；版本元数据更新至 7.3.0。
7.2.12026-10-25安全
  • 升级 async-nats 0.47、tokio 1.53.3、ctutils 0.4.4 与 rustls-webpki 0.103.16；cargo audit --deny warnings 通过。
  • 修复 MySQL 8.4/9 的 TLS REQUIRED 矩阵；live 测试失败时完整输出 cargo 错误。
  • 分片迁移遇到 BLOB/BYTEA fail-closed，新增 DualWrite；2PC 恢复用 xa_recover 交叉核对。
  • 归档滞后查询受超时约束、ClickHouse 半配置报错、WorkerHandle 并发等待修正；MSRV 1.88。
7.2.02026-10-25发布
  • 新增 ecat-data-sharding：分片路由/scatter/Snowflake/outbox/迁移，Consul/etcd 远程拓扑与健康探针。
  • 新增 ecat-data-tiering：MySQL 分区归档、ClickHouse/S3 冷层、TieredQuery、ecat-tier CLI 与归档滞后 readiness。
  • 新增 ecat-saga、ecat-data-2pc、fencing lock、Redis 共享池与 worker 生命周期接线；全部默认关闭。
  • MySQL 8.4/9 版本分支与认证矩阵；文档、i18n、静态站与 Social Preview 同步更新。
7.1.12026-10-19安全
  • 升级 rustls 0.23.45 至 0.23.46，修复 RUSTSEC-2026-0346、0347、0348、0349。
  • 升级 quinn-proto 0.11.16 至 0.11.18，修复 RUSTSEC-2026-0338 至 0342，含两条 high。
  • 纯依赖升级，无 API 变更。
7.1.02026-10-18功能
  • 新增 ecat pet 子命令：list、show、export 覆盖 13 个矢量形态。
  • 主形象与 12 个表情全部改为纯矢量 SVG，单一生成源，并用测试防止漂移。
  • Social Preview 重新生成，crate 数与后端数从 workspace 成员推导。
7.0.02026-10-08破坏性
  • 11 个后端 Config 新增 query_timeout_secs、breaker、max_concurrency；MongoConfig 新增连接池字段。结构体字面量构造属于破坏性变更。
  • 11 个后端接入统一出站外壳：许可、熔断、超时。
  • 13 个 crate 新增 metrics feature，from_config 自动注册出站指标。
6.0.02026-10-08破坏性
  • run_with_timeout 签名加入 BackendKind，错误类型改为泛型。
  • 删除公开静态量 QUERY_TIMEOUTS，由 TIMEOUTS 与 timeout_counter 取代。
  • RedisConfig 与 ClickhouseConfig 新增公开字段，结构体字面量构造属于破坏性变更。
5.0.02026-10-07破坏性
  • RdbmsError 新增 NoAvailableReplica，下游穷举 match 会编译失败。
  • Breaker、BreakerConfig、BreakerState、BreakerError 对外公开。
  • RdbmsRouting 可以跳过已熔断副本，并在副本全不可用时降级读主。
4.1.02026-10-06功能
  • 新增 ecat-orm 与 ecat-orm-derive。
  • #[derive(Entity)]、五套方言、类型状态查询构建器与标识符白名单。
  • CRUD、分块批量写入、分页与关联预加载。
4.0.02026-10-06破坏性
  • RdbmsClient 拆出 SqlExecutor supertrait。
  • Transaction 实现 SqlExecutor，空事务内执行 SQL 现在报错。
3.0.02026-08-14发布
  • MessageStream 改为 Bytes，mqtt 与 nats 走零拷贝路径。
  • 12 个数据 crate 统一 from_config 返回类型。
  • ecat-bench 的 BenchResult 新增 p95_latency_us。
2.3.02026-08-06数据
  • 真 Kafka、RabbitMQ、MQTT、NATS 后端。
  • MongoDB、S3、TDengine 后端，RedisLock、调度器与 OTLP 追踪。
  • RateLimitStore 与 Redis 限流存储。
2.1.72026-07-29数据
  • 新增 11 个数据库后端。
  • ecat-tls、WebSocket、API 版本路由、部署模板与 etcd 注册。
  • 工作区扩展成今天的生态。
