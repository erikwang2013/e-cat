实现步骤

第三部分：分阶段实现计划（共 7 个阶段）

Phase 1：项目骨架

Cargo Workspace 搭建 + 基础工具链
  • 创建 workspace Cargo.toml，配置 members
  • 搭建 ecat-protos crate —— 定义 errors.proto、metadata.proto
  • 搭建 ecat-errors crate —— 基于 protobuf 的错误码体系
  • 搭建 ecat-metadata crate —— 统一的元数据 key-value 传递
  • 搭建 ecat-encoding crate —— JSON + Protobuf 序列化
  • 搭建 ecat-logging crate —— tracing 集成 + 日志接口
  • CI 配置（GitHub Actions）：build + test + clippy + fmt

Phase 2：Transport 层

HTTP + gRPC 双协议支持
  • 搭建 ecat-transport crate —— 定义 Transport trait 和 Server trait
  • 搭建 ecat-transport-http crate —— axum 集成，HTTP Server
  • 搭建 ecat-transport-grpc crate —— tonic 集成，gRPC Server
  • 实现 HTTP/gRPC 的双向元数据传递（header ↔ metadata）
  • 实现优雅停机（graceful shutdown）支持

Phase 3：Middleware 体系

tower::Layer 中间件实现
  • 搭建 ecat-middleware crate —— 定义 Middleware trait（tower::Layer）
  • 内置 recovery 中间件（catch panic）
  • 内置 tracing 中间件（注入 trace_id / span_id）
  • 内置 logging 中间件（请求日志）
  • 内置 metrics 中间件（Prometheus 采集）
  • 内置 timeout 中间件
  • 中间件链组合器（tower::ServiceBuilder）

Phase 4：App 生命周期

应用编排 + 信号处理
  • 搭建 ecat 核心 crate
  • 实现 AppBuilder → App 生命周期管理
  • 实现多 Server 并发启动（HTTP + gRPC 同时运行）
  • 实现 OS 信号处理（SIGTERM/SIGINT graceful shutdown）
  • 实现 LifecycleHook（on_start / on_stop）
  • 典型使用示例:
let app = App::builder()
    .name("my-service")
    .http_server(http_srv)
    .grpc_server(grpc_srv)
    .with_registry(etcd_registry)
    .on_start(|| async { tracing::info!("started") })
    .build()?;

app.run().await?;  // blocks until SIGTERM

Phase 5：Registry & Config

服务注册发现 + 配置管理
  • 搭建 ecat-registry crate —— Registry trait + 内存实现
  • 搭建 ecat-registry-etcd contrib crate
  • 搭建 ecat-config crate —— ConfigSource trait
  • 内置 file/env 配置源
  • 实现配置热加载（watch 机制）
  • 搭建 ecat-metrics crate —— Prometheus 集成

Phase 6：CLI 工具

开发者工具链
  • 搭建 ecat-cli crate（使用 clap）
  • ecat new <name> —— 脚手架生成项目
  • ecat proto add <file> —— 添加 proto 文件
  • ecat proto client <file> —— 生成客户端代码
  • ecat proto server <file> —— 生成服务端代码
  • ecat run —— 开发模式运行（带热重载）
  • ecat build —— 生产构建

Phase 7：生态 & 文档

文档 + 示例 + contrib 生态
  • 参考文档（mdBook）—— 快速开始、核心概念、API 参考
  • 示例项目（examples/helloworld）
  • 项目模板（ecat-layout 仓库）
  • 更多 contrib crate：registry-consul、config-nacos、middleware-auth
  • 性能基准测试（benchmarks/）
  • 发布到 crates.io

以上 7 个阶段。确认后我将把这些内容整理成设计文档提交。
